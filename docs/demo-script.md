# 3-minute demo script

## 0:00–0:20 — Problem
“I interpreted the assignment as more than building a RAG chatbot. A field salesperson needs a trustworthy answer while standing with a retailer, so I designed around the moment of decision.”

## 0:20–0:55 — Product discovery
Ask: “Which Home Care brands target value-seeking consumers?”

Show the concise answer and citations.

## 0:55–1:25 — Product knowledge
Ask: “What is Surf Excel Smart Shots?”

Open the cited HUL document/page.

## 1:25–1:50 — Retailer mode
Ask: “Explain that to a retailer in simple language.”

Explain that this is a controlled reformulation of retrieved evidence, not free-form sales copy.

## 1:50–2:20 — Safety test
Ask: “What is the current distributor margin for Surf Excel?”

The correct response is an evidence-based refusal because the public corpus does not contain internal commercial terms.

## 2:20–2:45 — Architecture
Show network and data-flow diagrams.

## 2:45–3:00 — Production roadmap
“Given internal authenticated data, I would add territory-aware access, live scheme feeds, hybrid retrieval, multilingual voice, evaluation telemetry and feedback loops.”
